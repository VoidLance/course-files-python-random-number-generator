# Python Random Number Generator

A small Python script that generates an integer from 1 to 100, then displays
that value as an integer, a float, and a complex number.

## Why use it?

This beginner-friendly example demonstrates Python's built-in `random` module
and converting a number between numeric types. It has no third-party
dependencies.

## Get started

You need Python 3. Run the script from the project directory:

```bash
python "Random Number Generator.py"
```

The script prints a randomly selected integer, its float representation, and a
complex number with a randomly selected imaginary component. Both random values
are in the range 1–100, inclusive. For example:

```text
Random Number: 42
Type: <class 'int'>
Random Float: 42.0
Type: <class 'int'>
Random Complex: (42+17j)
Type: <class 'int'>
```

The type shown on each line is currently the type of the original integer
variable; the float and complex values themselves are still converted as
displayed.
